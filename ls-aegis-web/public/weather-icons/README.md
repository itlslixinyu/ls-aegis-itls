# 运营中枢天气图标（本地彩色 SVG）

自绘彩色图标，适配深色大屏，不依赖外网。

| 文件 | 天气 | 默认可预警 |
|---|---|---|
| `sunny.svg` | 晴 | 否 |
| `cloudy.svg` | 多云 | 否 |
| `rainy.svg` | 雨 | 否 |
| `storm.svg` | 暴雨 | 是（橙色） |
| `thunder.svg` | 雷电 | 是（黄色） |
| `hail.svg` | 冰雹 | 是（橙色） |
| `snow.svg` | 暴雪 | 是（黄色） |
| `fog.svg` | 大雾 | 是（黄色） |
| `sand.svg` | 沙尘 | 是（黄色） |

温度、湿度、风力另有独立预警规则，与天气现象预警互不合成。
