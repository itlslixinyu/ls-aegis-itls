> 日期：2026-08-15

| `前端表格规范.mdc` | **已建**（本仓库命名：`TableCol` / `constant/table-col.ts`） |

| `ColumnSetting` | 已存在；本地缓存会合并 `width`（`localCol.width \|\| col.width`） |

典型现网写法（用户管理等）：

```vue
<GiTable
  :scroll="{ x: '100%', y: '100%', minWidth: 1500 }"
  :columns="columns"
/>
```

列定义混用 `width` / `minWidth`，短列常无固定宽度，宽屏时易被均分拉宽。

以下第 1–11 节为目标方案；落地时按本项目路径与命名实现，**勿再使用业务线专属前缀**。

---

## 1. 目标观感

- 编号单行完整，不换行、不截断  
- 短列（状态/类型/数量/时间）紧凑、贴合内容  
- 名称列舒适宽度，超长省略 + tooltip  
- 宽屏多余空白留在**表格右侧**，不塞进某一列  

**不采用**：`scroll.x: '100%'` 列均分、按单元格自动测宽。

## 2. 架构与调用链

```
业务页 columns（只选角色/档位）
        ↓
   BaseTable
        ├─ normalizeTableColumns(columns)  → 全部列落到明确 width
        └─ mergeTableScroll(scroll, cols) → scroll.x = Σ width
        ↓
   GiTable → a-table
```

| 层级 | 路径 | 职责 |
|---|---|---|
| 业务列表页 | `ls-aegis-web/src/views/**/index.vue` 等 | 声明列语义，选用 `TableCol` |
| 档位常量 | `ls-aegis-web/src/constant/table-col.ts` | 编号/时间/状态等 px 档位 |
| 归一化工具 | `ls-aegis-web/src/utils/tableHelper.ts` | 锁宽、汇总 `scroll.x` |
| 表格壳 | `ls-aegis-web/src/components/BaseTable/index.vue` | 统一入口，禁止列表直连 `a-table` |
| 底层表格 | `ls-aegis-web/src/components/GiTable/src/GiTable.vue` | 工具栏、分页、列设置、全屏等（已有） |

## 3. 列角色（业务怎么写）

| 角色 | 业务写法 | 归一化结果 |
|---|---|---|
| 操作 | `dataIndex: 'action'` + `width: TableCol.action*` | `fixed: 'right'`，`ellipsis: false` |
| 短列 | `width: TableCol.date / status / type / qty …` | 保持 `width`，补齐 align / ellipsis / tooltip |
| 编号 | `minWidth: TableCol.code*` + `ellipsis: false`（不写 width） | 锁成 `width = minWidth`，`white-space: nowrap` |
| 名称 | 不写 width，或 `width: TableCol.name / nameLg` | 默认锁 **240**，`ellipsis` + `tooltip` |

默认 `align: 'center'`，业务可覆盖为 `left` / `right`。

### 业务示例

```ts
import { TableCol } from '@/constant/table-col'

const columns = [
  { title: '用户名', dataIndex: 'username', minWidth: TableCol.codeMinSm, ellipsis: false },
  { title: '昵称', dataIndex: 'nickname' }, // 默认 240
  { title: '所属部门', dataIndex: 'deptName', width: TableCol.nameLg }, // 需要更宽时显式指定
  { title: '状态', dataIndex: 'status', slotName: 'status', width: TableCol.status },
  { title: '创建时间', dataIndex: 'createTime', width: TableCol.date },
  { title: '操作', dataIndex: 'action', slotName: 'action', width: TableCol.actionM },
]
```

```vue
<BaseTable
  row-key="id"
  :data="dataList"
  :columns="columns"
  :loading="loading"
  :pagination="pagination"
  @refresh="search"
/>
```

## 4. 档位表（`TableCol`）

| 常量 | 值 (px) | 用途 |
|---|---|---|
| `codeMinSm` | 152 | 短编码 / 用户名等 |
| `codeMin` | 184 | 长单号 / 连续编号 |
| `codeMinLg` | 220 | UUID / 超长编码 |
| `type` / `typeSm` | 100 / 88 | 类型、标签 |
| `status` | 96 | 状态 |
| `date` / `dateSm` | 178 / 120 | 日期时间 / 仅日期 |
| `qty` / `unit` / `spec` | 88 / 72 / 120 | 数量、单位、规格 |
| `name` / `nameLg` | 240 / 320 | 名称默认 / 加宽 |
| `actionS` / `actionM` / `actionL` / `actionXl` | 140 / 220 / 280 / 360 | 按操作按钮数量 |

多页同类列不对时，优先改 `TableCol` 或 `normalizeTableColumns`，不要逐页抠 CSS。

## 5. 归一化算法（`normalizeTableColumns`）

对每一列：

1. **`dataIndex === 'action'`**  
   → `fixed: 'right'`，`ellipsis: false`，无 width 时兜底 140  
2. **已有 `width`**（短列 / 显式名称宽）  
   → 补齐 `ellipsis` / `tooltip` / `align`  
3. **无 width 且 `ellipsis === false`**（编号）  
   → `width = minWidth`，删除 `minWidth`，`bodyCellStyle.whiteSpace = 'nowrap'`  
4. **其余（名称等）**  
   → `width = minWidth ?? 240`，删除 `minWidth`，开启省略与 tooltip  

常量：`DEFAULT_NAME_WIDTH = 240`，操作列兜底 `140`。

## 6. 滚动策略（`mergeTableScroll`）

| 项 | 默认 | 说明 |
|---|---|---|
| `scroll.x` | `sum(各列 width)`（数字） | 禁止默认 `'100%'`，避免列被均分拉宽 |
| `scroll.y` | `'100%'` | 表体占满 GiTable 剩余高度，分页贴底（既有布局） |

容器比列宽总和更宽 → 右侧留白；更窄 → 横向滚动。

现网 `minWidth` 与 `x: '100%'` 组合在落地后应淘汰；由 `scroll.x = Σ width` 承担横向下限。

## 7. BaseTable 行为摘要

- `inheritAttrs: false`，其余 props/事件经 `v-bind` 透传给 `GiTable`  
- 插槽原样转发  
- 壳样式仅 `width: 100%`  
- 列表页**必须**用 `BaseTable`，不要裸用 `GiTable` / `a-table` 绕过归一化  

## 8. 与 GiTable / 列设置的关系

- GiTable 负责工具栏、分页、列显隐、全屏等；开发环境可开单元格边框便于调宽  
- 列设置本地缓存可能残留旧 width；改档位后若观感异常，点 **列设置 → 重置**  
- 列设置合并时，宽度以业务 / normalize 后的 props 为准，避免本地残留覆盖（落地时需核对 `ColumnSetting` 的 `localCol.width || col.width`）  

## 9. 禁止项

- ❌ `scroll.x: '100%'` 做列均分  
- ❌ 默认自动测宽布局  
- ❌ 名称列「吃光剩余宽度」铺满  
- ❌ 编号开启 ellipsis 截断，或档位过窄导致换行  
- ❌ 百分比列宽  
- ❌ 列表绕过 `BaseTable` / `normalizeTableColumns`
