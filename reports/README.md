# 报告目录

本目录统一存放项目本地报告，格式固定为 **Markdown（`.md`）**。

## 约定

1. 新增报告一律生成 `.md`，放入本目录对应主题子目录，不要散落在仓库根目录或其它模块下。
2. 文件名建议：`主题-日期.md` 或 `主题.md`（如 `国密功能测试报告.md`）。
3. 同类主题优先合并为一份报告，避免「互为补充」的多文件分散；附录可放探针数据。
4. 不使用 `.json` / Canvas / 临时 txt 作为正式报告落盘格式。
5. 报告内容默认中文；结论、统计、用例明细写清楚，便于复盘。

## 目录结构

```
reports/
├── README.md          # 本索引
├── 安全/              # 安全审计、外连、加固回写（合并为一份）
├── 国密/              # 国密功能验证
├── 前端/              # 前端规范与实现差异
└── 清理/              # 仓库整理、死代码与规范清理
```
