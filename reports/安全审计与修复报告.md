## 6. 运维与部署注意

1. **密钥**：复制 `docker/.env.example` → `docker/.env`，填写强随机值；**禁止提交** `docker/.env`。
2. **已有 MySQL 数据卷**：首次初始化后的 root 口令不会随环境变量自动变更；改密需 `ALTER USER` 或 `docker compose down -v` 重建（会清空库）。
3. **历史泄露密钥**：仓库中曾出现的 RSA/AES/JWT 弱值视为**已暴露**，即使已删除亦应轮换；若存量字段曾用旧 AES 加密，迁移前谨慎开启 `gm.legacy-aes-fallback`。
4. **改配置后**：需重新 `mvn -pl com.ls:ls-demo -am package -DskipTests`，jar 放入 `docker/ls-aegis-server/bin/`，前端 `npm run build` 同步 `docker/nginx/web/`，再 `docker compose up -d --build`。
5. **生产**：`JWT_SECRET_KEY`、`DB_PWD`、`REDIS_PWD`、国密密钥等必须由密钥管理/环境注入，禁止回退弱默认。
