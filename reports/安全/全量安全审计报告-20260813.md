## 8. 局限说明

1. 静态审计 + 代码修复，未做动态抓包、渗透测试、依赖 CVE SCA 全量扫描。  
2. `docker/nginx/web/static` 哈希包未逐文件逆向；前端风险以 **源码** 与构建入口为准（部署需重新构建同步 dist）。  
3. 开放 API 签名（Sa-Token sign）属产品能力，需保护 `sys_app` 密钥。  
4. 种子哈希仍对应历史默认口令：依赖 **强制改密** 与部署后口令轮换；仓库不再写明文。

---

## 9. 部署注意（修复后）

1. 已有库：重启后 Liquibase 执行 `patch_security_audit_hardening.sql`；或手工对齐 `init.sql` 效果。  
2. 本地存储目录：由 `../data/file/` 改为 `data/file/`，确认进程工作目录下存在该路径（Docker 已挂载 `/app/data/file/`）。  
3. 使用默认种子口令登录后会进入「密码已过期」页，须先改密。  
4. MySQL/Redis 仅本机可达；远程运维请走 SSH 隧道或调整 compose（勿对公网放开）。  
5. 前端改动需重新 `pnpm build` 并同步 `docker/nginx/web`。
